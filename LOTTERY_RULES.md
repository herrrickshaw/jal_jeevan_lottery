# Jal Jeevan Lottery: Detailed Rules & Regulations

## Part 1: General Rules

### 1.1 Lottery Administration
- **Administering Authority**: State Lottery Boards (coordinated by Jal Jeevan Mission Authority)
- **Regulatory Framework**: Lottery Regulation Act, 1998 (amended)
- **Ticket Issue**: Weekly/Bi-weekly/Quarterly (tiered)
- **Draw Method**: Computer-aided draw (RNG certified)

### 1.2 Ticket Eligibility
- **Age Requirement**: 18 years or above
- **Citizenship**: Indian nationals only
- **Exceptions**: No restrictions on married women, divorced individuals
- **Employee Restriction**: Government officials cannot hold office AND purchase tickets (conflict of interest)

### 1.3 Ticket Pricing & Denominations

| Tier | Name | Price | Frequency | Prize Pool |
|------|------|-------|-----------|-----------|
| I | Green (Rural) | ₹50 | Weekly | 35% |
| II | Blue (Urban) | ₹200 | Bi-weekly | 45% |
| III | Gold (Premium) | ₹500 | Quarterly | 50% |

### 1.4 Monthly Purchase Caps
```
Per Individual (per state):
  - Green: Max ₹2,000/month (40 tickets)
  - Blue: Max ₹2,000/month (10 tickets)
  - Gold: Max ₹2,000/month (4 tickets)
  
Aggregate: No individual may purchase >₹2,000 across all tiers/month
```

## Part 2: Ticket Structure & Serial Numbers

### 2.1 Green Ticket Serial Format
```
JJG-[STATE-CODE]-[YYYYMM]-[6-digit serial]-[1-digit check digit]

Example: JJG-RJ-202607-123456-7

Components:
  JJG: Jal Jeevan Green identifier
  RJ: State code (Rajasthan)
  202607: Month-year of issue
  123456: Unique serial (000001 to 999999)
  7: Luhn algorithm check digit (anti-counterfeiting)
```

### 2.2 Blue Ticket Serial Format
```
JJB-[STATE-CODE]-[YYYYMMDD]-[8-digit serial]-[2-digit check]

Example: JJB-UP-20260715-12345678-42

Components:
  JJB: Jal Jeevan Blue identifier
  UP: State code (Uttar Pradesh)
  20260715: Exact date of issue (day-specific)
  12345678: Unique serial (00000001 to 99999999)
  42: Dual-digit checksum (prevents duplicate spoofing)
```

### 2.3 Gold Ticket Serial Format
```
JJAu-[YEAR]-[CORPORATE-ID]-[4-digit serial]-[STATE-CODE]

Example: JJAu-2026-TATA001-1234-MH

Components:
  JJAu: Jal Jeevan Gold (Au = Aurum/Gold)
  2026: Calendar year
  TATA001: Corporate/HNI identifier (Aadhaar-linked)
  1234: Unique serial (0001 to 9999)
  MH: State of purchase
```

## Part 4: Prize Claim Procedure

### 4.1 Claim Timelines
```
Prize Amount | Claim Period | Claim Location | Processing Time
≤ ₹10,000    | 30 days      | Any ticket vendor/post office | 2 hours
₹10,001–₹1,00,000 | 60 days | District lottery office | 3–5 days
₹1,00,001–₹50,00,000 | 90 days | State lottery board HQ | 7–14 days
>₹50,00,000  | 180 days     | High Court + Lottery Board | 30–45 days
```

### 4.2 Required Documentation
```
For All Winners:
  ✓ Original winning ticket (no photocopies)
  ✓ Valid ID proof (Aadhaar, PAN, Passport)
  ✓ Proof of address (recent utility bill, rental agreement)
  ✓ Bank account details (cancelled cheque)
  
For Prizes >₹1 Lakh:
  ✓ TDS certificate (30% tax deducted at source)
  ✓ PAN card (mandatory)
  ✓ Income tax return (last 2 years)
  
For Prizes >₹50 Lakh:
  ✓ Affidavit (notarized)
  ✓ Credit report verification
  ✓ Background check (anti-money laundering)
```

### 4.3 Tax Treatment
```
TDS Calculation (at source):
  Prize ≤ ₹10,000: Nil tax
  ₹10,001–₹1 Crore: 30% TDS
  >₹1 Crore: 35% TDS (surcharge applicable)
  
Income Declaration:
  Lottery winnings = "Income from Other Sources" (Section 56, ITA)
  Combined with other income for progressive slab calculation
  
Deduction Allowed:
  50% of prize amount if donated to Jal Jeevan Mission (Schedule 80G)
  
Example:
  Win: ₹2,00,000
  TDS: ₹60,000 (30%)
  Net received: ₹1,40,000
  If donated ₹1,00,000 to JJM → ₹50,000 tax deduction (next year)
```

### 4.4 Unclaimed Prize Distribution
```
If Prize Unclaimed After 180 Days:
  - 50%: Revert to prize pool (next draw)
  - 30%: Jal Jeevan Mission emergency fund
  - 20%: State government water department
  
Permanent Unclaimed (after 3 years):
  - 100% → Jal Jeevan Mission corpus
  - Lottery board publishes list (newspaper + website)
  - Attempt to contact via registered mobile/email for 2 years
```

## Part 6: Fraud Prevention & Safeguards

### 6.1 Anti-Counterfeiting
```
Physical Security:
  ✓ Hologram with state emblem (can't photocopy)
  ✓ UV-reactive ink for 6-digit serial
  ✓ Microprint on edges (50-micron font)
  ✓ Watermark: "JEEVAN" pattern (visible under 10x magnification)
  ✓ Serial number embossed (not printed)

Digital Security:
  ✓ Blockchain registration (each ticket on distributed ledger)
  ✓ QR code with cryptographic hash
  ✓ NFC chip (optional, for ₹200+ tiers)
  ✓ Tamper-evident scratch-off (UV ink mix)
  
Verification Method:
  - Buyer scans QR → State database confirms original
  - Counterfeit QR returns: "Ticket not found" error
  - SMS to ticket purchaser on first scan
```

### 6.2 Draw Integrity
```
Live Draw Process:
  1. 60 minutes before draw: Lottery machines sealed (physical + digital)
  2. Random audit committee arrives (3 members)
  3. Machines opened live on camera
  4. Draw conducted in front of:
     - State lottery board CEO
     - Independent auditor (Big 4 firm)
     - Civil society representative
     - Broadcast live (DD News + YouTube)
  5. Results published immediately + signed certificate
  
Ticket Validation:
  - Random sample of 10,000 drawn tickets verified
  - Cross-check against blockchain ledger
  - Test for duplicates/counterfeits
  - Monthly audit by Comptroller & Auditor General (CAG)
```

### 6.3 Responsible Gaming
```
Addiction Prevention:

Monthly Spending Cap:
  - Per individual: ₹2,000 across all tiers
  - Enforced via Aadhaar + PAN linkage
  - System blocks further purchase if limit reached

Helpline & Support:
  - 1-800-JJM-HELP (toll-free, 24/7)
  - Counseling services (trained operators)
  - Mental health referral network
  - SMS support: "Worried about spending? Text STOP to pause 30 days"

Self-Exclusion Option:
  - Mobile app: "Self-Exclude for 30/90/180 days"
  - Prevent ticket purchase by vendor network
  - Restore after cooling-off period (can re-enable)

Awareness Campaigns:
  - Quarterly TV spots (Doordarshan, regional channels)
  - School assemblies: "Water matters, gambling doesn't"
  - Grassroots messaging in local languages
  - Celebrity PSA: "Win water, not debt"
```

## Part 7: Appeal & Dispute Resolution

### 7.1 Prize Claim Disputes
```
Dispute Types:
  A) Ticket declared invalid (claimed to be counterfeit)
  B) Serial number not found in draw database
  C) Multiple claims on same ticket
  D) Lost ticket (only stub remains)

Resolution Process:
  1. Complainant files affidavit + evidence
  2. State lottery board investigates (7 days)
  3. If ticket matches blockchain record → Prize awarded
  4. If no match → Refer to independent auditor
  5. If auditor confirms authenticity → Prize paid + compensation
  6. If fraud detected → Police complaint + ticket forfeiture

Appeals Timeline:
  - Initial decision: 14 days
  - Appeal to state board: 30 days
  - High court appeal: 180 days
  - Supreme court petition: No time limit (constitutional matter)
```

### 7.2 Draw Integrity Disputes
```
Allegation: "Draw was rigged / results published incorrectly"

Investigation:
  1. Immediate data audit (blockchain immutable ledger checked)
  2. Machine recalibration test (confirm RNG parameters)
  3. Video review of live draw broadcast
  4. Independent technical audit by accredited firm
  5. Report published within 30 days

Remedies:
  - If error found: Tickets re-drawn, all winners paid
  - If fraud confirmed: Criminal prosecution + compensation
  - Transparency: Full report available on state lottery website
```

## Part 9: Definitions

| Term | Definition |
|------|-----------|
| **Lottery Ticket** | Government-issued document entitling holder to participate in draw |
| **Prize** | Cash/non-cash reward following successful draw |
| **Serial Number** | Unique identifier linking ticket to draw participation |
| **Draw** | Random selection of winning serial numbers |
| **Consolation** | Participation prize (small amount) given to all tickets |
| **Bumper** | Special largest prize drawn quarterly/annually |
| **TDS** | Tax Deducted at Source (tax on prize money) |
| **Jal Jeevan Swap** | Voluntary redemption of cash prize as water connection credit |
